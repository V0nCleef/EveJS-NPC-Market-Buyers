NPCs buy your sell orders in single-player EveJS, using fair price references and randomised batches. Includes native sell advice, an in-game dashboard, configuration help, optional offline purchases and eight client languages.

This build makes the My Orders bars show **stock remaining**: full means everything is still for sale, and the bar drains as units sell. Captions and help text match it in all eight languages. Clear online Wallet descriptions and bundled offline income are included.

Requires Native EveJS **0.12.9**, Launcher **1.0.69+** and EVE client build **3396210**. Stop EveJS/native market, import **NPC-Market-Buyers-0.1.15.zip** through Launcher → Mods → Add ZIP, then restart and reconnect. Existing users must disable/remove the old package first; keep only one version enabled. Saved policy and purchase history stay outside the mod folder.

Download the attached Launcher ZIP rather than GitHub's automatic Source code archive. `SHA256SUMS.txt` identifies the reviewed package.
