# NPC Market Buyers 0.1.24

NPC Market Buyers now supports Docker installations through EveJS Launcher 1.0.80, alongside the existing Native backend. Docker support targets EveJS 261108.1 on Linux amd64.

- Keeps buyer settings, sales history and settlement data in the selected installation's persistent storage.
- Checks the selected market image and live market connection before recovering unfinished purchases.
- Adds guarded updates from 0.1.23, retaining pending work and rejecting modified financial source files.
- Retains the existing buying rules, Native market payload and in-game companion.

**Requires Launcher 1.0.80 or newer.** Download `NPC-Market-Buyers-0.1.24.zip`, then use **Mods > Add ZIP**, or use **Check mod updates** on a supported existing installation. Stop the selected stack before updating, retain a backup, then restart and reconnect normally. The `.update.json` attachment is updater metadata; import only the ZIP.

Focused installer, update, package and persistent-path checks passed. Docker gameplay, real market/wallet recovery and container lifecycle evidence comes from the earlier qualified private package; this release keeps its Linux runtime and financial implementation unchanged. The version-specific Native update guard was checked separately. A fresh Linux run was unavailable because Docker was off and was left off. Packaged candidate documentation records the earlier qualification stage; these notes describe the public release.

Source and artifact identities are recorded in `releases/0.1.24.json`. No live installation was changed during preparation.
