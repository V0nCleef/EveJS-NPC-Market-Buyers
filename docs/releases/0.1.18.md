# NPC Market Buyers 0.1.18

Fixes the **"Native baseline differs from this reviewed package"** error that prevented installation on normal EveJS setups.

- Removes native file-hash requirements, login-source fingerprints and the exact EveJS version lock.
- Backs up your actual market files and installs the included market executable and source. A precompiled executable is no longer required.
- Restores your original files when the mod is disabled or removed. Settings and sales history are retained.
- Fixes NPC purchase completion on clean stock EveJS installations.

Tested with clean Native EveJS 0.12.9, including real purchases, random batches, offline catch-up and restart recovery. Launcher updates and rollback also passed. The interface and buying settings are unchanged.

**Update:** Stop EveJS and the native market, close EVE, then use **Launcher → Mods → Check mod updates → Update**. Restart the stack and reconnect afterwards.

**New installation:** Download **NPC-Market-Buyers-0.1.18.zip** below, then use **Launcher → Mods → Add ZIP**. The `.update.json` attachment is for the Launcher's updater; import only the ZIP. GitHub's **Source code** downloads are not installable mod packages.

Requires the Native Windows backend and Launcher 1.0.69 or newer. Docker is not supported. Other EveJS versions are no longer blocked by an exact version check, but have not all been tested.
