**NPC Market Buyers — EveJS mod**

Released a mod that lets NPCs buy your sell orders in random batches, as long as the price is fair. The normal sell window shows price advice, buying chance and possible batch size.

Includes TQ hub or EVE average pricing with automatic backups, Unlimited/Limited buying modes, optional offline purchases, and My Orders/Activity windows with Icons, Details and List views. Offline income is bundled, so you don't return to a wall of wallet popups.

Install the ZIP through **Launcher → Mods → Add ZIP** with the stack stopped. After restarting, open **Mods → NPC Market Buyers** in game.

**Download + showcase:**
https://github.com/V0nCleef/EveJS-NPC-Market-Buyers/releases/tag/v0.1.15
